# ClaudeCode
This project aims to reproduce the workflow from Markus Academy in order to facilitate future projects and provide a template for other automation requests. 

Markus K. Brunnermeier, director of Princeton's BCF, is the host of the Claude Code video series, and Paul Goldsmith-Pinkham, professor at Yale School of Management, is the speaker illustrating the implemented workflow. The Claude Code video series can be best accessed on [Substack](https://markusacademy.substack.com/p/claude-code-for-applied-economists).

Manual verification is always an issue with AI outputs. By reproducing the process, we can leverage the content creators' professional knowledge in the field, given they have done their due diligence in verifying the results produced by AI. We would simply compare our output with theirs. 

## The ClaudeCode Deployment Process
The deployment process of Claude Code is not intuitive in the video. It is easier to install on MacOS and Linux. Here is how you can deploy it on Windows PowerShell:
1. Have an AI API ready. It can be a Claude subscription, Claude API, or any API provided by the subscription to any AI platforms. This means <ins>you do not need to subscribe to Claude to use Claude Code</ins>. Save the API key since Claude will ask you for it later. 
2. Open PowerShell. You may do so by pressing [Windows Key + R] or [Windows Key + S], then type in "PowerShell" and press Enter. E.g., the former shortcut will open the window below where you can type in the characters.
   
   <img width="620" height="318" alt="image" src="https://github.com/user-attachments/assets/7ee42895-a93a-47e1-8e48-286b274f2841" />

   
3. Download ClaudeCode:

```powershell
  winget install Anthropic.ClaudeCode
```

4. Close the current PowerShell window. Open a new PowerShell window by following the same procedure in step 2. Enter:

```powershell
     claude
```

   ClaudeCode is successfully installed if you see Claude Buddy in your PowerShell:
   
   <img width="764" height="330" alt="image" src="https://github.com/user-attachments/assets/c4fac2c6-1dd6-45d4-81f1-4fd01019a89d" />

  The text exhibit might vary, as Claude Code is not working yet.

5. Enter the following in your PowerShell window to open the ClaudeCode JSON file:

```powershell
cd ~
notepad.exe .\.claude.json
```

Locate "firstStartTime" and "machineID," enter the following line between the two:

```json
"hasCompletedOnboarding": true,
```

<img width="975" height="189" alt="image" src="https://github.com/user-attachments/assets/735a98a8-4a41-401f-8957-24b73c138be0" />

6. Restart PowerShell following step 2. Enter "Claude" again and follow the instructions to set up your API. You should now have full access to ClaudeCode.

## US Homeowner Age Analysis

The first project is to plot the US homeowner age group. Prompts are provided below (same as in the video), and outputs, including raw data and Python and R scripts, can be found in folder "test2," where ClaudeCode conducted the job.

```prompt_1
  I'm starting a new project from scratch. I want to analyze how the 
  age distribution of homeowners in the US has changed over the last 
  50 years. I think the Census Bureau publishes homeownership rates 
  by age of householder from the Census. Potentially, the data is 
  available through the Census website or through FRED.
  
  Download homeownership rates by age going back as far as possible. 
  Write this as download_data.py. Save the raw data as a CSV.
```
```prompt_2
  Please make a script to generate a figure in R with this data. 
  Please follow the best practices of making figures from Kieran Healy.
```

# General Tips for Using AI
1.	20+ turns, start fresh
2.	Write current ideas to files and store them. Context will expire, but files won't
3.	Break work into chunks to make each session more focused
4.	If Claude keeps circling, interrupt, say “we’ll do this again. Forget about what happened 2 minutes ago."
5.	If you use your Claude at 7am, it resets at 12pm, and you will enjoy twice the token limit
6.	Kieran Healy has a set of rules on visualization in R. Asking Claude to follow the practice in your prompt is a shortcut to optimize the visual job. Similar practice is applicable to other requests if there is a standard or example you would like AI to look at.
7. For larger jobs, context is important. Knowing the background, expected outputs, restraints, etc., can help clarify the job at the beginning.
8. Using an "indifferent" tone would help save tokens. Remove "please" and "thank you." Your tone does affect the output.
